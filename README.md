# M-manu Tap

## How do I install these formulae?

`brew install m-manu/tap/<formula>`

Or `brew tap m-manu/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "m-manu/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
